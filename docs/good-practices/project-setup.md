# Od czego zacząć projekt?

Zanim rozpoczniecie realizację swojego pomysłu, przygotujcie repozytorium Git. Będzie ono miejscem przechowywania kodu, dokumentacji i historii zmian.

Na początek wystarczą dwa pliki:

* **README.md** — krótki opis projektu, informacje o autorach oraz wybranej licencji.
* **.gitignore** — lista plików, których Git nie powinien śledzić.

Zainicjalizujcie repozytorium i zapiszcie pierwszy commit:

```bash
git init
git add .
git commit -m "Inicjalizacja projektu"
```

**Dobra praktyka:** zadbajcie o podstawową organizację projektu, zanim zaczniecie pisać kod.
